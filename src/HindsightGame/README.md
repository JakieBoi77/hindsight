# Hindsight: Ophthalmology Game (Unity PoC)

Proof-of-concept vertical slice for the Development Plan (§10): a child-friendly,
step-by-step **Eye Drops** walkthrough.

Title → Level Select (Eye Drops unlocked, other clinic visits "coming soon") →
Eye Drops (11 steps) → sticker reward.

## Requirements

- Unity **6000.6.2f1** (see `ProjectSettings/ProjectVersion.txt`), with the Android
  and/or iOS build modules for device builds.
- JetBrains Rider (recommended in the Development Plan) or any C# IDE.

## Getting started

1. Open `src/HindsightGame` in Unity Hub (**Add → Add project from disk**).
2. Open `Assets/_Project/Scenes/MainMenu.unity` and press **Play**.

Pressing Play in any scene works: `GameBootstrapper` is spawned from `Resources`
before the first scene loads. Opening `Procedure.unity` directly runs Eye Drops.
In editor and development builds, the grey **Skip** button jumps past a step.

Progress is saved to `Application.persistentDataPath/progress.json`. Delete it to
reset the unlocks and stickers.

### Architecture in one paragraph

A level is a `ProcedureDefinition` (ScriptableObject) holding an ordered list of
`StepDefinition` assets. Each step type (Dialogue, DilationDemo, TapTarget, Quiz,
HoldStill, TapCount, Examine, Reward) pairs with a `StepView` prefab that presents it.
`ProcedureController` runs the steps with `ProcedureSession` (pure C#) and hands each
view a `StepContext`, which provides the doctor, the speech bubble and the sounds.
Interaction rules (`HoldStillChallenge`, `TapGoal`, `QuizEvaluator`, `UnlockRules`)
live in `Hindsight.Core` and are unit tested. App-wide services (`GameServices`) are
created once by `GameBootstrapper`.

### Adding or editing content

- **Change wording:** edit the step assets in `Data/Procedures/EyeDrops/Steps`. Every
  `DialogueLine` has a **Narration** slot for recorded voice-over.
- **Add a procedure:** create a `ProcedureDefinition` (Create → Hindsight → Procedure),
  add step assets (Create → Hindsight → Steps → …) and add it to `ProcedureCatalog`.
- **Check content:** run **Hindsight → Validate Procedure Content**. The same checks run
  as an EditMode test.

### Art

All illustrations are original placeholders generated by
`Tools/ArtGen/generate_placeholder_art.py` (`python Tools/ArtGen/generate_placeholder_art.py`).
SVGs import as sprites through `ArtImportPostprocessor`. Replace any file in place
(keeping its name) to upgrade the art without touching prefabs.

## Tests

Use **Window → General → Test Runner**, or run headless:

```
Unity -batchmode -projectPath . -runTests -testPlatform EditMode -testResults TestResults/editmode.xml
Unity -batchmode -projectPath . -runTests -testPlatform PlayMode -testResults TestResults/playmode.xml
```

- **EditMode:** core rules, progress persistence, and content validation (for example,
  "cold" and "sting" are warned about before the drop goes in).
- **PlayMode:** an end-to-end run where an auto-player taps, holds and answers
  quizzes (wrong answers first). It plays Eye Drops to the reward and checks that
  progress is saved.
- **CaptureStoryboard** (explicit) saves a screenshot of every screen to
  `TestResults/Screenshots`, for design and clinician review.

## Builds

From **Hindsight → Build**, or headless:

```
Unity -batchmode -quit -projectPath . -executeMethod Hindsight.Editor.Build.BuildScripts.BuildAndroid
Unity -batchmode -quit -projectPath . -executeMethod Hindsight.Editor.Build.BuildScripts.BuildIos      # then open in Xcode on a Mac
Unity -batchmode -quit -projectPath . -executeMethod Hindsight.Editor.Build.BuildScripts.BuildWindows
```

Output goes to `Builds/` (git-ignored).

## Regenerating the scaffold (rarely needed)

The scenes, prefabs and data were bootstrapped by code so the setup is reproducible:

1. **Hindsight → Setup → 1. Configure Project Settings** (player, URP, input).
2. **Window → TextMeshPro → Import TMP Essential Resources** (once per clone if missing).
3. **Hindsight → Setup → 2. Scaffold PoC Content (overwrites)**.

Step 3 **overwrites** the generated scenes, prefabs and data. After the first commit,
edit those assets in the Editor instead.
