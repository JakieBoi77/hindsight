## Ophthalmology Game POC

Title screen → level select → **Eye Drops**, a 14-step walkthrough of an eye-drop visit. The camera cuts between Cinemachine shots and switches to first person once the child sits in the chair. Steps: greeting, why drops are needed, pupil-dilation close-up, sit in the chair, two quiz questions, a cold/sting heads-up, tilt back and hold your eye open (letting go "blinks" and the drop misses), blink to spread the drops, a look inside with the light, and a reward.

### Open and run

1. In Unity Hub choose **Add → Add project from disk** and pick `src/OphthalmologyGame` (editor 6000.6.2f1, with the Android and/or iOS modules).
2. Open `Assets/_Project/Scenes/Menu.unity` and press Play. For a tablet-shaped view, switch the Game view to **Simulator** and pick an iPad or Android tablet.

### How it is organised

```
Assets/_Project/
  Scripts/Core/         levels, level catalog, progress (PlayerPrefs), scene flow
  Scripts/Procedure/    ProcedureDefinition + ProcedureStep ScriptableObjects, ProcedureRunner
  Scripts/Procedure/Steps/  Dialogue, ShowCloseup, TapTarget, Quiz, HoldStill, Blink, Exam, Reward
  Scripts/Scene/        ExamRoomContext (what steps can touch), ShotDirector (Cinemachine), DoctorActor, rigs
  Scripts/UI/           dialogue, quiz, action buttons, eyelid/blur overlays, reward, HUD, menu, level cards
  Art/Icons/            SVG icons from the 2D prototype (imported via Unity's vector graphics module)
  Art/UI/               generated anti-aliased shape sprites (rounded panel, circle, ring, play, check)
  Scripts/DevTools/     PocAutoPilot (smoke test, only active with -autopilot)
  Editor/               PocBuilder (+ .Ui) / PrefabBuilder / UiKit (generate everything), ShotCapture
  Data/                 level + step assets (edit dialogue and quiz text here)
  Prefabs/              ExamRoom, ExamChair, Doctor, EyeDropBottle, Ophthalmoscope, EyeModel
  Scenes/               Menu, EyeDrops
Assets/ThirdParty/      downloaded models (see THIRD_PARTY_ASSETS.md)
```

- **Adding a level** is mostly data. Create step assets (right-click → Create → Ophthalmology → Steps/…), list them in a Procedure Definition, add a Level Definition to `Data/LevelCatalog.asset`, and give it a scene that has an `ExamRoomContext` and a `ProcedureRunner`.
- **Swapping art.** Each prefab keeps its gameplay components on the root and its model under a `Visual` child, so a better model replaces `Visual` without touching code. The doctor's animations are matched by clip-name suffix (`|Idle`, `|Wave`, ...) in `DoctorActor`.
- **Camera shots** are the `CinemachineCamera` children of `Shots` in the EyeDrops scene. Steps refer to them by name.
- **UI style** comes from the 2D prototype: the Fredoka font, navy "ink" outlines, chunky two-tone buttons, round icon buttons and picture cards. `UiKit` holds the palette and widgets. Shape sprites are generated at high resolution with anti-aliased edges, and corner radii are set per widget, so buttons stay sharp at any tablet resolution.

### Regenerating

The prefabs, step assets and scenes are generated by **POC → Rebuild All** (`PocBuilder.BuildAll`). It is safe to rerun, but it overwrites hand edits to the generated scenes and prefabs. Edit step text in `Data/` freely: the builder rewrites those assets too, so for lasting dialogue changes edit the strings in `PocBuilder.BuildEyeDropsProcedure` (or stop using the builder once the POC graduates).

Headless equivalents (run from `src/OphthalmologyGame`, with `Unity` = the 6000.6.2f1 editor executable):

```sh
Unity -batchmode -projectPath . -executeMethod Hindsight.Ophthalmology.EditorTools.PocBuilder.BuildAll -quit
Unity -batchmode -projectPath . -runTests -testPlatform EditMode -testResults results.xml
Unity -batchmode -projectPath . -buildTarget Android -executeMethod Hindsight.Ophthalmology.EditorTools.PocBuilder.BuildAndroid -quit
```

### Smoke test

**POC → Build Windows (smoke test)**, then run
`Builds/Windows/OphthalmologyGame.exe -screen-fullscreen 0 -autopilot <folder>`. It plays the whole level, including one deliberate blink, saves a screenshot of every state into `<folder>`, and exits with code 0 if nothing logged an error.

### Known POC shortcuts

- Art is mixed from free packs, so styles don't fully match. The doctor is the KayKit "Rogue" with her gear removed and her tunic recoloured into a white coat. Her belt and gloves are still the adventurer's.
- The doctor's wave and talking (mouth and head bob) are procedural layers in `DoctorActor`. The pack has no wave or talk clips, so they're simple.
- The "blur" after the drops is a white haze overlay, not a real blur shader.
- There is no audio or voice-over yet.
- iOS builds need a Mac. Unity only exports the Xcode project on Windows.
